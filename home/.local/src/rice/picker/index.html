Pick a palette and a wallpaper

Every palette comes from a real code editor theme. Every wallpaper was made by people: photographers, open-source artists, and the tools developers already use. I recoloured each one into the palette you pick with lutgen, the tool ricers use for this. When you like it, copy your picks and paste them back into the terminal.

Shaped like your 1920×1200 screen. Full screen shows it at real size.

      
    

  


  

    
1Palette

    
This one colour set goes everywhere: bar, window borders, terminal, lock screen, browser, Discord, btop and cava. Five are built into Caelestia already. I'd build the other three myself.

    

  


  

    
2Wallpapers

    
Pick one or more. If you pick several, they rotate. The ones tagged "Moves on charger" play live while you're plugged in and pause on battery, so they don't drain power. Some come in two versions; switch between them under the picture.
