Dashboard media GIFs (Caelestia, patch: media-gif-random).
The Media widget picks a random meme each time the track changes:
first a random meme, then a random file of it. Files are grouped by the
part of the name before the first "-" or ".", so clippy-1.gif and
clippy-2.gif count as one meme. Drop in any .gif/.webp to add more.
Empty folder = Caelestia's normal bongo cat.
